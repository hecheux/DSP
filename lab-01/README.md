# DSP Lab 1

## Анализ сигнала во временной и частотной области

### О чем работа

В программе выполняется построение сигнала во временной области, его амплитудного и фазового спектров, анализ влияния zero padding, восстановление сигнала с помощью обратного БПФ и построение спектрограммы.

### Что сделал

Cгенерировал сигнал по заданной формуле, построил его график во временной области и выполнил дискретное преобразование Фурье. 
Дальше построил амплитудный и фазовый спектры, сравнил представление спектра в bin и в герцах, проверил влияние добавления нулей, восстановил исходный сигнал через обратное БПФ и построил спектрограммы для разных окон.

### Как работает

Сначала программа формирует сигнал по заданным параметрам и строит его график во времени. 
Затем вычисляется БПФ, по которому строятся амплитудный и фазовый спектры. 
После этого анализируется zero padding, чтобы посмотреть, как меняется отображение спектра. 
Потом с помощью обратного БПФ восстанавливается сигнал и считается ошибка восстановления. 
В конце строятся спектрограммы, которые показывают, как энергия сигнала распределена по времени и частоте.
