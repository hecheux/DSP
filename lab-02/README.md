# DSP Lab 2

## Разложение функции в тригонометрические ряды Фурье

### О чем работа

В работе рассматривается функция на интервале от 0 до P. 
Для нее строятся частичные суммы косинусного и синусного рядов Фурье и 
сравнивается, насколько хорошо они приближают исходную функцию.

### Что сделал

Я задал исходную функцию, вычислил коэффициенты косинусного и синусного 
рядов Фурье через интегралы и построил частичные суммы для N = 10, 50 и 200. 
Также сравнил точность приближения для разных чисел членов ряда и отдельно проверил, 
что коэффициенты, посчитанные вручную для N = 10, совпадают с коэффициентами, найденными по формулам.

### Как работает

Сначала программа задает функцию и вычисляет коэффициенты рядов Фурье. 
Затем для разных значений N строятся частичные суммы косинусного и синусного рядов. 
После этого на графиках сравниваются исходная функция и полученные приближения. 
В конце программа считает максимальную ошибку приближения и проверяет совпадение ручных расчетов с вычислениями по формулам.
